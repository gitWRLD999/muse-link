Muse Link is extracted from the working Muse/OpenClaw connection layer.
It includes original bridge code and the MIT-licensed SideScreen adapter from
https://github.com/gitWRLD999/sidescreen (copyright 2026 gitWRLD999).

OpenClaw workspaces, browser profiles, credentials, recovered private tools,
SideScreen binaries, and CUA Driver are not included. Optional Playwright MCP
and the MCP SDK retain their upstream licenses. Configurable external engines
retain their own licenses and installation requirements.
